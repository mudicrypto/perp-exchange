## 2. How the extraction is checked

```sh
node scripts/oss-extraction-check.mjs                     # report to stdout; exit 1 on a blocking finding
node scripts/oss-extraction-check.mjs --stage /some/dir   # also run the extraction stand-alone
```

The script only reads the repository and, with `--stage`, copies files to a directory outside it. It
publishes nothing and writes no licence.

| Check | Blocking? |
|---|---|
| Relative imports that leave the manifest | yes |
| Packages outside the allowed set: runtime `zod`; test `vitest`, `fast-check`; Node built-ins | yes |
| Test-only packages used by non-test code | yes |
| Licences of every used package and its installed transitive dependencies | yes, if not permissive |
| Secret patterns in the included files **and in every historical version of those paths** (private keys, Stellar seeds, API keys, tokens, assigned secrets) | yes |
| Review terms (names, paths, personal addresses, notes) | no; listed for a decision |
| Authorship of the included paths | no; input for the IP review |
| `--stage`: copy files and a minimal scaffold (private, `UNLICENSED`), then run typecheck, the test suite and the showcase | yes, if any fails |
